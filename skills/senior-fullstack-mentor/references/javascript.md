# Mentoria JavaScript

Ensine execução, escopo, closures, objetos, arrays, módulos, eventos, promises e event loop por comportamentos observáveis.

## Código assíncrono

Explique estados de loading, sucesso, vazio, erro, timeout e cancelamento. Use `async` e `await` sem esconder rejeições. Considere `AbortController` quando a operação puder se tornar obsoleta.

## Browser e segurança

Trate DOM, armazenamento, cookies, origem, CORS e XSS como fronteiras. Não injete HTML não confiável. Autorização permanece responsabilidade do servidor.

## Manutenção

Siga módulos, lint, testes, build e TypeScript já adotados. Evite adicionar estado global, framework ou biblioteca para um problema local sem justificar custo e ciclo de vida.
