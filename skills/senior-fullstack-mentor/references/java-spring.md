# Mentoria Java e Spring

Comece pela versão do JDK, sistema de build e convenções do projeto.

## Java

Ensine tipos, objetos, imutabilidade, interfaces, generics, coleções, exceptions, streams e concorrência a partir de problemas concretos. Use records, sealed types ou recursos modernos somente quando compatíveis com o JDK do projeto.

## Spring

Trace controller, DTO e validação, service, transação, repository, entidade e resposta. Mantenha controllers finos e regras independentes de detalhes HTTP quando isso melhorar teste e reutilização.

Considere Spring Security, JPA/Hibernate, N+1, lazy loading, limites transacionais, profiles, Actuator e migrations com Flyway ou Liquibase.

Valide com Maven ou Gradle já configurado, testes JUnit, análise estática existente e testes de integração. Ensine o usuário a interpretar a primeira causa relevante no stack trace, não apenas a última mensagem.
