# Mentoria HTML e CSS

## HTML

Ensine estrutura semântica antes de aparência: landmarks, títulos, listas, links, botões, formulários, labels, mensagens de erro e ordem de foco. Use ARIA para complementar, não substituir, semântica nativa.

## CSS

Ensine cascade, herança, especificidade, box model, fluxo, flexbox, grid e posicionamento. Prefira tokens e classes com intenção clara. Preserve o sistema visual existente.

## Qualidade

Considere teclado, contraste, foco visível, zoom, redução de movimento, conteúdo dinâmico, responsividade e layout shift.

Ao orientar um layout, explique primeiro a hierarquia e o comportamento nas larguras relevantes. Depois forneça uma alteração pequena de HTML/CSS e peça validação visual e funcional.
